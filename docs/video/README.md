## Before you use it

- The voice-over has 237 words, not 390. Barnaby speaks during the demo, and the voice-over must not talk over him. Add words only in gaps.
- **Not tested:** a tour with navigation ON in the newest build. The 1:15 line claims VS Code opens files and highlights lines. Run it once before recording. If it fails, delete that half sentence and say only that he says where to look.
- The 2:10 line about Claude Code is optional. Skip it if Connect Claude Code is not set up. Then the captions after 130 s need shifting by 20 s.
- Captions were timed by estimate, not by listening to a recording. Re-time them in YouTube Studio after upload.

## YouTube title

Barnaby: a desktop pet who reads your code out loud

## YouTube description

Barnaby is a Windows desktop pet. Ask about your code by typing or by voice. He reads the project with Meta's Muse Spark, answers out loud in a British voice, and walks you through the files in VS Code.

0:00 Meet Barnaby
0:15 He reacts when you pick him up and drop him
0:35 Ask a question about your code
1:15 A guided tour in VS Code
1:50 Turn navigation off in Settings
2:10 Watching coding agents
2:30 What it is built with

Built with Meta Model API (Muse Spark), Phonon text to speech, Tauri 2, Rust, TypeScript, and a VS Code extension.
Only the project folder you choose is read.

Code: https://github.com/Vachilla64/barnaby

## Voice-over

**0:00 to 0:15**
Opening code you did not write is hard. Meet Barnaby. He lives on my desktop, and he reads code out loud.

**0:15 to 0:35**
He is a pet, so he reacts. Pick him up, and he panics. Let go, and he falls, bounces, and settles on the floor.

**0:35 to 1:15**
I ask a question about my project: how does login work? Show me. Barnaby sends the question to Muse Spark, through the Meta Model API. Muse Spark reads the project files itself. Then Barnaby answers out loud, in a British voice. The answer takes about twenty seconds, so I have cut the wait.

**1:15 to 1:50**
Then he gives me a tour. He says where to look, in words, like: look at lines one to ten of validate dot t s. VS Code opens each file and highlights the lines, while Barnaby turns his back and points.

**1:50 to 2:10**
If you do not want him touching your editor, one switch in Settings turns it off. He only tells you where to look, and VS Code stays still.

**2:10 to 2:30**
He also watches coding agents. When Claude Code finishes a task, he tells me, so I can look away from the terminal.

**2:30 to 2:50**
Muse Spark, through the Meta Model API, is the brain. The voice is Phonon, and it runs on my own computer. A small extension drives VS Code, and the pet is a Tauri overlay. Only the project folder I choose is ever read.

**2:50 to 3:00**
Barnaby. The link is below.
