## YouTube title

Barnaby: a desktop pet who reads your code out loud

## YouTube description

Barnaby is a Windows desktop pet for people whose code was written by AI. Ask about your own code by typing or by voice. He reads the project with Meta's Muse Spark, answers out loud in a British voice, and walks you through the files in VS Code.

1:32 A guided tour in VS Code
2:02 Turn navigation off in Settings
2:17 Watching coding agents
2:37 What it is built with

Built with Meta Model API (Muse Spark), Phonon text to speech, Tauri 2, Rust, TypeScript, and a VS Code extension.
Only the project folder you choose is read.

Code: https://github.com/Vachilla64/barnaby
