You vibe coded it. Do you understand it?

An AI agent can write a whole project in an afternoon. Then you are left with code you did not write and cannot explain. Barnaby reads your project and walks you through it, out loud, one file at a time.

What he does

Walks you through your code

Ask "how does login work? show me." He reads the project and gives a tour. He says where to look in words. If you allow it, VS Code opens the file and highlights the lines too.

Has a personality

He is an old British gentleman with a top hat and a monocle. He speaks in a British voice. Pick him up and he panics. Drop him and he falls and bounces.

Any agent can talk to him

Barnaby runs a local MCP server. Claude Code and Gemini CLI link through the app. Other agents that speak MCP can connect by hand. He tells you out loud when an agent has finished.

Ask by typing, or hold the push-to-talk key and speak.

How it works

  1. You pick a project folder. Barnaby can only read that folder.
  2. You ask a question, typed or spoken.
  3. Meta's Muse Spark model reads the files it needs and writes the answer, plus a list of tour steps.
  4. Phonon, a voice engine on your own computer, speaks the answer in Barnaby's voice.
  5. The VS Code extension opens each file and highlights the lines, if tour navigation is switched on.

Barnaby is a small always-on-top pixel pet. Pick him up and he panics. Drop him and he falls and bounces. During a tour he turns his back and points.

Privacy

  • Only the project folder you choose is read.
  • Only your question and the code needed to answer it go to Meta's API.
  • Window titles and anything outside that folder are never sent.
  • The local server listens on 127.0.0.1 only and checks a token.
  • Your API key is kept in Windows Credential Manager.
  • The voice runs on your own computer.
