# Barnaby

A desktop pet for each of your AI coding agents. The agents tell their pet what they are doing, and the pet tells you out loud. Ask a pet about your codebase and it walks you through the code in VS Code, file by file, while it talks.

Built for the Meta Global AI Developer Hackathon with **Muse Spark** (Meta Model API) and **Phonon TTS** (local).

> Status: spec stage. The product spec is [docs/SPEC.md](docs/SPEC.md); build progress is in [docs/TASKS.md](docs/TASKS.md). Coding agents: start with [AGENTS.md](AGENTS.md).
